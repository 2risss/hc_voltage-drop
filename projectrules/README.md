# 压降测算小工具 — 项目规则

默认的用户规则仍然生效。本目录只补充本项目约定。

## 已确认决策

- 形态：手机可打开的静态网页（H5 + PWA），可添加到主屏幕，断网也能计算。
- 托管分两阶段：先在企业版 `github.tesla.cn` 做内网备份版（GitHub Pages）；公网开源仓库以后再建，不要把原 Excel/宏上传到任何仓库。
- 内网仓库英文名：`hc_voltage-drop`（以后公网建议用同一名字）。页面中文标题：「压降验证测算」。
- 公式：JSON 配置和网页放在同一个仓库；改 JSON 后推送即可，页面显示公式版本号。断网时使用已缓存的公式。
- 安全：只读 JSON，不执行外部 JS；计算和历史只留在手机本地；提供一键清空；不保存姓名、电话、地址。
- 品牌：可用简洁专业的家充风格配色，不使用 Tesla 官方 Logo / 商标。
- 第一版完成标准：压降、压降百分比、末端电压、载流量、热损失、电源容量；可加到主屏幕；最近 10 条本地历史；断网可用。
- 三相最低末端电压：完全按原表宏的比较顺序（不是标准三者取最小）。
- 电缆类型、单相「车载充电机」：界面保留作备注；单相车载充电机不参与计算，三相车载充电机参与取计算电流。
- 内网仓库：https://github.tesla.cn/luying/hc_voltage-drop ；系数和载流量表允许随内网仓库给同事看到。原 Excel/宏仍不上传。
- 公式来源：`data/压降计算公式.xlsm`（只读）。网页公式从同仓库 JSON 加载，版本号单独显示。

## 必须遵守

- 不要把计算公式写死在页面代码里。
- 禁止上传用户数据到任何外部接口或云服务。
- 不要覆盖 `data/` 或原始 `压降计算公式.xlsm`。
- 执行任务前先列出步骤，等确认后再做；每完成关键步骤先汇报，再继续。
- 所有项目文件放在本项目路径内。

## 文件位置

- `data/` 原始资料（只读）
- `output/` 生成结果
- `scripts/` 脚本
- `temp/` 临时文件
- 网站源码放在项目内约定目录，不散落到项目外
